# Activos visuales

Los fondos `static/assets/epilover-brand-es.png` y `static/assets/epilover-brand-en.png` provienen del kit oficial EpiLover/WCE 2027 entregado por la usuaria para este prototipo. El repositorio no afirma derechos adicionales sobre marcas, logotipos o ilustraciones.

El archivo `static/assets/world-countries.geojson` utiliza límites cartográficos de **Natural Earth**, escala 1:110m. Natural Earth publica estos datos en dominio público. La copia se almacena dentro del proyecto para que el mapa funcione sin servicios cartográficos externos.

- Fuente oficial: <https://www.naturalearthdata.com/downloads/110m-cultural-vectors/>
- Conversión GeoJSON consultada: <https://github.com/datasets/geo-boundaries-world-110m>
